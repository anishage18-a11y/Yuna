## Important

These pages were tailored to the supplied Yuna codebase after reviewing its major cogs, SQLite databases, AI system, tracking, ticket/transcript, backup, moderation/security and third-party API functionality.

Notable data practices reflected in the Privacy Policy include:

- Discord user/guild/channel/role identifiers
- Message content processing for AI, moderation, automod, autoresponder, counting, AFK and related features
- 24-hour AI conversation memory cleanup
- Separate AI chatbot history with no automatic expiry in the current implementation
- Saved AI personality preferences
- Message-count and invite tracking
- Level/XP data
- AFK information and reasons
- Ticket metadata, ratings and ticket-channel transcripts
- Server backups containing roles, channels, permission overwrites and emoji URLs
- Todo tasks and other user/server configuration
- In-memory snipe/edit-snipe data
- Operator-controlled command-completion webhook logging
- Third-party processing through Groq and feature-specific search/media/weather/crypto/content APIs

## Before publishing

1. Make sure the operator name, email and jurisdiction are accurate.
2. Make sure the email account is monitored for privacy/deletion requests.
3. Host the HTML files publicly over HTTPS.
4. Add the public Terms of Service and Privacy Policy URLs to the Discord Developer Portal.
5. Keep the policy updated when Yuna's data practices or third-party providers change.
6. If Yuna is operated commercially or serves users in jurisdictions with detailed privacy requirements, have the documents reviewed by a qualified lawyer.
